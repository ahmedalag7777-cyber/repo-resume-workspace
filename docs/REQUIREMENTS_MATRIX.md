# مصفوفة المصالحة الواحدة — الرسالة التنفيذية وV6

الحالة بتاريخ 2026-10-27. الوثيقة الأساسية الأصلية غير متاحة بمحتوى صالح؛ الرسالة التنفيذية المرفقة واضحة ومقروءة وليست فارغة. لا نسقط متطلبات V6 بسبب غياب الأصل ولا نعلن مقارنة لم تُجر.

## خريطة العقل والقلب الحالية

- **العقل:** `universal/pipeline.ts → profile.ts → canonical-schema/semantic-field-mapper → runCapabilities/derivedCapabilities → advise.ts`، مع `matrix.ts` حين تسمح بيانات الشهور. لا محرك مكرر ولا استيراد من legacy.
- **القلب:** `analyze.tsx → parseFile → مراجعة الجدول → analyzeTable → analyses/work_tasks`، ثم `analyses.$id.tsx` لقراءة النتيجة و`tasks.tsx` للمهام. بصمة الملف محفوظة، الصلاحيات القائمة لم تتغير.
- **مصدر الحقيقة الحالي:** خلايا الجدول المقروءة و`sourceRows` للمؤشرات، ونتيجة التحليل المحفوظة للعرض. `audit` يربط الاستبعادات والترويسة واختلاف العرض والصيغ؛ `verification` يعيد جمع الخلايا. المصدر الأصلي الكامل ليس محفوظاً، لذا إعادة تشغيل الملف بعد فقده غير مضمونة.
- **قبل/بعد:** قبلاً قد يُحذف عميل كبير كإجمالي، ويصبح المفقود/المرتجع صفر نشاط، ويستخدم توصيف الأعمدة جمعاً عائماً؛ الآن هذه الحالات مغطاة باختبارات، المجاميع عشرية وسجلها ظاهر في تبويب المصدر والتحقق.

## ترتيب التنفيذ التالي

1. P1: تحسين القاموس الحالي ومراجعة المعاني؛ علاقات مشروطة بعينة تحقق دون اختلاق معاني.
2. P2: توحيد المؤشرات/الوحدات، Drill-down والفلاتر، دورة حياة وحفظ مهام موثوق.
3. P3: سيناريوهات وتصدير ومساعد مرتبط بالدليل؛ لا اعتماد على مزود مدفوع.
4. P4: أداء وأمان وعزل ومراجع OCR/صيغ وتراخيص بيانات اللغات.

كل عنصر يبقى مفتوحاً حتى اختباره؛ لا تبديل للحالة بسبب وجود اسم مكتبة أو شاشة فقط.
